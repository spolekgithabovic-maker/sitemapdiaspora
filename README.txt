САЙТ DIASPORA CARE z.s. — ВЕРСИЯ 5
====================================

Как устроена папка
  index.html          — стартовая страница: сама открывает сайт на языке посетителя
  ru/ uk/ cs/ en/     — сайт на русском, украинском, чешском и английском
  assets/content.js   — НАСТРОЙКИ, которые можно править самим (см. ниже)
  assets/i18n.js      — все тексты сайта на 4 языках
  assets/style.css    — оформление
  assets/app.js       — работа сайта (навигатор, разговорник, формы и т. д.)
  assets/fonts, img   — шрифты, логотип, баннер, иконки
  sw.js, manifest     — работа без интернета и установка на телефон
  robots.txt, sitemap.xml, 404.html — для поисковиков и GitHub Pages

Что можно менять самим — файл assets/content.js
  ORG      — IČO и дата регистрации
  PHOTOS   — фото основателей (файлы положить в assets/img)
  DONATE   — ссылка на Darujme.cz, цель и собранная сумма
  EVENTS   — встречи (там есть пример, как добавить)
  NEWS     — новости (сейчас там примеры с плашкой «Пример»)

Публикация на GitHub Pages
  1. Загрузите ВСЁ содержимое этой папки в корень репозитория sitemapdiaspora.
  2. Settings → Pages → Source: «Deploy from a branch», ветка main, папка / (root).
  3. Сайт откроется по адресу https://spolekgithabovic-maker.github.io/sitemapdiaspora/
  4. Если подключите свой домен — попросите Claude заменить адрес в файлах
     (канонические ссылки, sitemap.xml, robots.txt, 404.html).
  5. После любых изменений файлов увеличьте номер VERSION в sw.js
     (например dc-v5-2), чтобы у посетителей обновилась сохранённая копия.

Перед публикацией
  - Отправьте тестовое сообщение через форму и подтвердите письмо от FormSubmit.
  - Покажите политику конфиденциальности юристу.
  - Получите согласие Терезы, Анны и Тани на публикацию историй и фото.
